## Beute wie im Original
- Im Raum schwebt keine Beute mehr. Sie steckt im Objekt (Kasse, Wertschrank), wie im Original.
- Wer Beute nimmt, trägt einen Beutesack auf dem Rücken (Original: lsAddLootBag).
