# Release Candidate RC63 – Der Einbruch

## Beute im Grundriss
- Der goldene Hinweis erscheint in der Planung. In der Wiedergabe verschwindet er, sobald die Beute genommen ist.
- Beim Überfahren eines Beutefelds steht immer der Wert: „Beute: Kassenlade – 4.000 €, Gewicht 0,5 kg“. Nach dem Nehmen steht „genommen“.
- Liegt zusätzlich ein Planhinweis auf dem Feld, kommt er darunter.
