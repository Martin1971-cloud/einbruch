# Release Candidate RC61 – Der Einbruch

## Laufwege (Punkte 3 bis 5)
- Versatz: Wege mehrerer Personen liegen an Engstellen nebeneinander statt übereinander.
- Hover: Über einem Haltepunkt oder einem Objekt (Tür, Vitrine, Beute) zeigt eine Hilfe Person und Aktion.
- Legende unter dem Grundriss: Farbe = Person, Zuordnung zu Nummern. Der Eintrag „Geplanter Weg“ zeigt jetzt, dass die Farbe die Person bezeichnet.

## Tests
- Planung, Klick, Tür, Einsteigen, Reichweite, freie Bewegung und Ablauf-Test bestehen.
