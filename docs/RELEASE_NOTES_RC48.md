# Release Candidate RC48 – Der Einbruch

## Weg 3, Schritt C: feiner Grundriss in Planung und 3D
- Grundriss (2D): Der Kiosk wird aus den Rechtecken des feinen Grundrisses gezeichnet: Innenraum, dünne Wände, Fenster, Türen (zu/offen) und Vitrinen.
- 3D: Wände, Fenster, Türen und Vitrinen werden aus denselben Rechtecken gebaut. Die Sockel entfallen, die Vitrine ist ein Rechteck.
- Figuren, Sichtkegel und Laufwege nutzen die feinen Positionen (seit RC46 und RC47).

## Offen
- Die Planung klickt noch auf ganze Felder. Ein Klick auf eine Vitrine oder Tür wählt das Feld. Das ist beabsichtigt, weil die Planung auf Feldern bleibt.
- Museum und weitere Ziele nutzen noch den Grundriss aus ganzen Feldern. Sie können auf dasselbe Format umgestellt werden.
